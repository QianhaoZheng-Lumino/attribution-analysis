> **用法：** 写 ES「后续动作」前 **必须 Read 本文件**。导语和六键怎么写给人看，见 [es-writing.md](./es-writing.md)。

> 一案最多 **1–2 条**。本表 **不改定责**。D 组兑现 → 对内。

## 漏斗三个量（必须分开写，禁止混用）

| 名字 | 字段 | 正常同向时 |
|------|------|------------|
| **查价请求（总量）** | `total_search` / PPS total | 渠道要搜多少 |
| **有价请求** | `avail_search` | 通常随总量 **同比例** 变 → **有价率不变** |
| **有价率** | `avail_search / total_search` | 有价没跟总量走才会动 |
| **验价** | `total_rp` | 渠道拿去核价的量 |
| **查验比** | `avail_search / total_rp` | **缩小** = 价更有优势（同加价表：降价→验价↑→查验比↓） |
| **产量** | BKS | 独立看，不由查价单独决定 |

**关房**只打有价/产量，**不解释查价总量涨跌**（A2 已强调）。

## Agent 自检

**1. 查价不变时，验价两条必须对称**

| | 验价升 | 验价降 |
|--|--------|--------|
| 查验比 | **缩小** = 价更优 | **增加** = 价更劣 |
| 编号 | **A3** | **A7**（对称 A3，不是覆盖） |
